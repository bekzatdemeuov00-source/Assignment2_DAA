## Реализация

`DynamicArray` хранит данные в `int[]`. При заполнении выделяется массив вдвое больше,
и значения копируются циклом. Вставка и удаление по индексу сдвигают элементы.

`MyLinkedList` использует узлы с двумя полями: `int value` и `Node next`.
`head` указывает на начало, `tail` — на конец. Для доступа по индексу нужен последовательный обход.

`MinHeap` хранит дерево в `int[]`. Для индекса `i` родитель имеет индекс `(i - 1) / 2`,
левый ребёнок — `2 * i + 1`, правый — `2 * i + 2`.
Вставка поднимает новый элемент; извлечение заменяет корень последним элементом и опускает его.

## Инвариант DynamicArray.contains

В начале итерации с индексом `i` ни один элемент с индексом меньше `i` не равен искомому значению.

1. Инициализация: при `i = 0` проверенный префикс пуст, утверждение верно.
2. Сохранение: если текущий элемент совпал, метод возвращает `true`.
   Иначе он также не равен запросу, поэтому после увеличения `i` утверждение сохраняется.
3. Завершение: при `i = size` все элементы проверены, поэтому возвращается `false`.
   Индекс увеличивается на каждой продолжающейся итерации, значит цикл завершается.

## Инвариант MinHeap.bubbleDown

В начале итерации поддеревья детей текущего `index` являются кучами.
Все связи родитель–ребёнок упорядочены, кроме возможных связей текущего элемента с его детьми.

1. Инициализация: после замены корня последним элементом только корень может нарушать порядок.
2. Сохранение: выбирается меньший ребёнок. Если текущий элемент не больше него,
   порядок восстановлен. Иначе обмен исправляет связи на текущем уровне,
   а возможное нарушение перемещается в выбранного ребёнка.
3. Завершение: цикл заканчивается при правильном порядке или при достижении листа.
   Каждый обмен перемещает индекс на уровень ниже; высота конечна. Вся структура снова является кучей.
